# 이어하기 — 선굴활룡대전 카오스 시드 (새턴 JP Rev B)

비공개 저장소. ROM·세이브스테이트·디스크에서 뽑은 파일·빌드 결과물은 없다(로컬에만). **클라우드에서는 번역만** 하고, 빌드·실기는 로컬에서 한다.
상세 분석은 `docs/01_초기조사.md`(끝 절들이 최신).

## 1. 클라우드 번역 (2026-10-01 준비)

### 파일
- 원문: `work/text/chaosseed_001‥042.tsv`(29KB 단위, 대사 스크립트) — 고유 14,179문장 · 약 24.9만 자. **원문 파일은 고치지 말 것.**
- 원문: `work/text/ovl_001‥.tsv`(메뉴·시스템 메시지·시나리오 설명·도움말 — 실행 파일 안 문자열 235개, 4,432자)
  - «구분» = `메뉴:NB` → **원래 N바이트 안에 들어가야 한다**(제자리). 한글 1자 = 1~2바이트(자주 쓰는 음절 1) → 대략 «원문 글자 수» 안으로 짧게. 검사기가 넘칠 듯하면 ⚠.
  - `번역금지` = 이름 입력판 한자 표 — 비워 둘 것(검사기 오류) · `잡음?:NB` = 2~3자 조각(대개 데이터) — 뜻이 안 되면 비워 둘 것.
  - 여기서 `
` 은 메뉴용 줄바꿈(바이트 05), `{06}` 은 시나리오 설명의 줄바꿈 — 둘 다 원문 자리 그대로.
- 번역: 원문 파일을 `work/ko/` 에 같은 이름으로 복사해 **«번역» 열만** 채운다. 배치마다 `python tools/kocheck.py` 로 검사(오류 0이어야 함).
- 열: `ID · 위치 · 구분 · 공유 · 원문 · 번역`
  - 위치 = `SSS묶음/항목:오프셋`(같은 장면의 앞뒤 문맥 찾기용), 공유 = 같은 문장이 나오는 자리 수(한 번 번역하면 전부에 들어감).
  - 구분: `대사:XX`(XX = 화자 번호 — 같은 번호면 같은 인물) · `안내`(지명·상황 해설) · `글`(선택지·연속 대사 뒷부분·시스템 글) · `영문`(크레딧·개발용 — **번역하지 말고 비워 둘 것**) · `검증필요`(추출기가 확신 못 하는 172줄 — 번역은 하되 이상하면 비워 둠)
- 개발용 시험 문구(«トークテスト», «デバッグ» 등)도 그냥 번역해도 된다.

### 제어 토큰 (원문과 **같은 순서·같은 개수** 그대로 — 검사기가 막는다)
| 표기 | 뜻 |
|---|---|
| `\n` | 줄바꿈 — **원문 자리 그대로**(개수 같게). 대사는 엔진이 알아서 접으니 새로 넣지 말 것 |
| `{p}` | 쪽 넘김(버튼 대기 후 새 쪽) |
| `{03:nn}` | 잠깐 멈춤(글자 찍기 대기) — «は～{03:03}～» 처럼 끌기 연출 |
| `{05:nn}` | 이름 변수(`{05:00}` = 주인공 이름 등) — 조사는 받침 없는 이름도 자연스럽게(«{05:00}님», «{05:00}, …») |
| `{04:nn}` `{07}`‥`{0A}` `{c:XXX}` | 그 밖의 제어·특수 — 그대로 둔다 |
| 끝의 `{00}` | 출력 후 메시지 닫기 — 그대로 |
| `{A}{B}{X}{Y}{LV}` `◀▶■` | 버튼·특수 그림 글자 — 그대로 |

### 조판·문자 규칙
- 번역에 **가나·한자를 남기지 말 것**(글꼴의 가나·한자 칸을 한글로 덮어쓴다).
- 글꼴에 있는 기호만: `! ? 。 、 ， ． ・ ‥ ～ ー ― （ ） 『 』 「 」 ： ／ ＋ ＆ ％ ♡ ○` 와 숫자, **대문자** A‥Z. 라틴 소문자 없음. «…» 는 `‥`, «~» 는 `～`.
- 문장부호 뒤 공백은 빌더가 지운다(전 프로젝트 규칙) — 넣어도 되지만 의미 없음.
- 일본어 고유명사(가타카나)는 **거센소리**: か행=ㅋ · た행=ㅌ · つ=츠 (⛔외래어표기법의 어두 예사소리 금지).
- 말투: 원문 말투를 살린다(노인 «～じゃ» → «～구나/～느니라», 무사 «拙者»·«ござる» → «소인»·«～이오», 존댓말/반말 그대로). 같은 화자 번호는 같은 말투로.

## 2. 로컬 현재 상태
- ✅ 디스크 `tools/disc.py`(ROM 경로 260자 초과 → `\\?\`) · 압축 `tools/lz.py`(풀기 + **압축기 `compress`·항목 교체 `replace_item`**)
- ✅ 대사 = `SSS0‥13.ADT` 스크립트, 인코딩 = 1바이트 0x20‥0xFF / 2바이트 0x18‥0x1F, 글꼴 = 0.BIN 0x78F66(1,664자, 12×14) `tools/font.py` · 코드표 `tools/tbl.py`
- ✅ 해석기 모델 `tools/vm.py` · 추출기 `tools/extract.py` · 검사기 `tools/kocheck.py`
- ✅ PoC `tools/poc.py`(1문장 같은 길이 교체) 트랙 1 `4e80a294…` ✅실기 성공(띄어쓰기 12px 로 넓음 → 반각 조사)
- ✅ **삽입기 `tools/insert.py [--ko 폴더] [--install]`**: 대사는 길이 같으면 제자리, 다르면 «63 점프 → 항목 끝 새 문장 → 63 복귀»(다른 오프셋 안 건드림, vm.walk 로 검산) · 글자표는 쓰임 바이트순 1바이트 157칸 → 2바이트 · 오버레이는 제자리 예산 · ⛔풀린 스크립트 항목 ≤ 9,220 B(RAM 버퍼). 시험 번역으로 빌드·검산 통과(실기 전).
  - ⚠큰 항목(최대 8,209 B)은 번역이 길면 버퍼를 넘을 수 있다 → 넘치면 그 항목만 옛 문장 자리 재활용·오프셋 고쳐 이어 쓰기로 보완 예정.
- ✅ 오버레이 추출 `tools/ovl_extract.py`(05 = 줄바꿈, 2-그램 점수로 거름) → work/text/ovl_*.tsv · work/ovl.json
- ⏳ 8×8 셀 묶음(HELP.BIN 0x1E524 — 라벨 그림·8×8 가타카나·영숫자) 한글화 방식 결정 필요
